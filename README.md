# Playback Speed Calculator

A Playback Speed Calculator made to calculate total time and time saved on a video with its playback speed like 2x, 3x etc. 

Demo: https://playback-calculator.vercel.app

## 🛠️ Tech Used:
- Next.js
- Tailwind CSS
- React
- [Flowbite docs](https://flowbite.com/docs/getting-started/next-js/).
